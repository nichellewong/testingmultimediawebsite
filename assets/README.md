Put your photos, videos, and data files (timeline.json, storymap.json) in this folder.

On GitHub: open this folder, click "Add file" > "Upload files", drag your files in, and click "Commit changes".

Then refer to a file by its name in content.md, for example:

    source: my-photo.jpg

Keep names simple (lowercase letters, numbers, dashes). Each file must be under 25 MB.
